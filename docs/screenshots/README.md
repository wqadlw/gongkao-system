## 规范

- **格式**：PNG 或 JPG 均可
- **分辨率**：1280×720 以上，单文件 < 500KB（GitHub 会自动缩略）
- **脱敏**：公开仓库会暴露个人题库/笔记内容，截前确认可接受公开
- **文件名必须与上表完全一致**，否则 README 图链失效
- 更新界面后请同步替换对应截图
