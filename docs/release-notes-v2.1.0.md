# 公考行测知识库系统 v2.1.0

**Windows 桌面版首发** —— 免 Python 环境，下载安装即用。

## 下载

| 文件 | 说明 |
|------|------|
| `GongKaoSystem-Setup-2.1.0.exe`（51MB） | Windows 安装包：开始菜单/桌面快捷方式/卸载器 |

## 安装说明

1. 下载安装包，双击运行（如 SmartScreen 提示，选择「仍要运行」——开源未签名应用）
2. 按向导完成安装，启动后自动打开浏览器（http://127.0.0.1:7080）
3. 个人数据保存在 `%LOCALAPPDATA%\GongKaoSystem\data`，卸载不会删除你的数据库

## 本版核心功能

- **题库 19,365 题**：国考+省考真题 11,270 题自带五维深度标注（推理链/最快解法/易错点/母题抽象），LogiQA 逻辑推理 8,004 题
- **FSRS 科学复习**：Anki 同款记忆算法，支持用个人复习日志训练专属参数
- **资料库 11,147 份**：思维导图 51 张（预览+下载）、考点精讲 10,375 条（与真题 qid 关联）、材料档案 717 份（按年份分类）
- **模考模式**：限时组卷、答题卡、按模块计分、逐题复盘
- **离线 OCR 录题**、Anki 牌组导出、全局搜索、学习手册导出、明暗双主题

## 从源码运行

见 README：`git clone` 后 Windows 双击 `install.bat` + `start.bat`。
