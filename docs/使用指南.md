## 一、v2.0 核心升级（相比v1）

| 升级项 | v1.0 | v2.0 |
|--------|------|------|
| **提示词输出格式** | Markdown文本 | **结构化 Markdown（`####` 分节）**，系统直接解析 |

| **公考倒计时** | 无 | **新增**国考/省考倒计时模块 |
| **字段结构** | 15个字段 | **18个字段**，新增细分考点/考察意图/难度标签/考场优先级 |

## 三、快速开始

### Windows用户
1. 解压压缩包到任意目录
2. 双击 `install.bat`（首次安装，自动创建虚拟环境+安装依赖）
3. 双击 `start.bat` 启动系统
4. 浏览器自动打开 `http://localhost:7080`

### Linux/Mac用户
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
cd frontend && npm install && npm run build && cd ..
./start.sh
```

## 四、核心使用流程（v2极简版）

### 完整链路（只需4步）

```
① 粉笔APP刷题 → 遇到有价值/不会的题目 → 截图
        ↓
② 系统选考点 → 复制对应模块提示词
        ↓
③ 打开外部AI → 粘贴提示词 + 发送题目截图 → AI 返回 Markdown 文本
        ↓
④ 系统粘贴AI返回的Markdown文本 → 自动解析入库 → 完成！
```

### 详细操作

#### 第1步：选择考点
1. 进入「题目录入」页面
2. 选择模块（政治理论/常识判断/言语/数量/判断/资料）
3. 选择三级考点（如：数学运算）
4. 选择四级考点（如：排列组合问题）
5. 系统自动匹配对应模块的提示词模板

#### 第2步：复制提示词
1. 点击「复制提示词」按钮（复制纯提示词）
2. 或点击「组装提问文本」（提示词+题目信息）

#### 第3步：外部AI处理
1. 打开任意AI工具（ChatGPT/Claude/文心一言/通义千问/Kimi等）
2. 粘贴提示词
3. 发送题目截图
4. AI 会返回**带 #### 分节的结构化 Markdown 文本**

#### 第4步：粘贴入库
1. 回到系统「题目录入」页面
2. 将AI返回的**完整内容**粘贴到右侧文本框
3. 点击「解析预览」
4. 系统自动提取所有字段
5. 确认无误后点击「确认入库」

### 备考笔记追问

提示词末尾会询问"是否需要整理该考点的备考笔记？"

当你回答"需要"时，AI 会输出结构化备考笔记（以下为内部字段示意）：

```json
{
  "question_display": "题目原文",
  "type_judgment": "题型判定",
  "knowledge_points": "涉及的知识点",
  "logic_chain": "解题逻辑链",
  "solve_steps": "标准简洁的解题步骤",
  "pitfalls": "避坑要点",
  "speed_tips": "考场提速技巧"
}
```

将此内容粘贴到「笔记管理」页面的"生成笔记"功能中，系统自动解析存储。

## 八、常见问题

### Q1：AI返回的不是严格的 Markdown / JSON 格式怎么办？
**A**：系统优先按 Markdown（`####` 分节）解析；若未发现分节标题则尝试 JSON 兜底；最后退回纯文本原样保留。建议提示词中要求"使用 `####` 一级标题分节输出结构化内容"。

### Q2：解析后部分字段为空？
**A**：检查AI返回的JSON是否包含该字段。可手动在详情页补充编辑。

### Q3：如何修改考试倒计时日期？
**A**：进入「考试倒计时」页面 → 点击「编辑」→ 修改日期 → 保存。

### Q4：考点树为什么没有"全部"节点了？
**A**：v2已优化，删除冗余的"全部"节点，直接展开三级题型节点，更清晰。

### Q5：数据存储在哪里？
**A**：纯本地SQLite文件 `data/gongkao.db`，可随时备份/迁移。

### Q6：可以在多台电脑使用吗？
**A**：复制整个项目目录或仅复制 `data/gongkao.db` 文件即可。
