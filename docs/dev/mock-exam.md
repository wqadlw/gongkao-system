# 设计文档：模考模式（Roadmap #1）

状态：已实现 | 日期：2026-10-01

## 需求

限时整卷模拟考试：组卷 → 限时答题（答题卡）→ 交卷按模块计分 → 历史成绩与错题复盘。
复用既有 `MockExam` 表（模考成绩：六模块分数字段与系统六大模块一一对应）；
新增 `mock_questions` 表存每次模考的试卷快照与作答记录。

## 组卷

- 模式一（按模块）：勾选六大模块（多选）+ 总题数 → 从题库按模块随机抽题（`ORDER BY RANDOM()`，按模块配额均分，余数给第一个勾选模块）。
- 模式二（按来源）：指定真题卷来源（`source` 精确匹配）→ 抽取该卷全部题目。
- 时长：默认 `题数 × 45 秒`，可自定义（分钟）。

## 作答与计分

- 开始模考即建 `MockExam`（score 置 0）与 `mock_questions` 快照（题目、模块、正确答案）。
- 交卷（手动或倒计时结束自动）：逐题判分 → 更新 `mock_questions.selected/is_correct`
  → 按 六大模块 写入 `MockExam.score_*`（该模块答对数），`total_score` = 总答对数。
- 未作答题目按错误处理（is_correct=0）。
- 复盘接口返回：成绩汇总 + 每题（题干/你的答案/正确答案/解析），跳转题目详情可看深度标注。

## 接口

| 接口 | 说明 |
|------|------|
| POST /api/mock/start | 组卷并开始（返回试卷，不含答案） |
| GET /api/mock/list | 历史模考列表（含完成度） |
| GET /api/mock/{id}/paper | 取未完成模考的试卷（断点续答） |
| POST /api/mock/{id}/submit | 交卷判分，返回成绩单 |
| GET /api/mock/{id}/result | 复盘：成绩 + 逐题作答与解析 |
| DELETE /api/mock/{id} | 删除该次模考 |

## 前端

`/mock`（学习分组，「模考模式」）：历史列表 → 组卷表单 → 答题界面（倒计时/答题卡/上一题下一题）→ 成绩单与错题复盘。
